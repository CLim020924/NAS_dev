# NAS AI 에이전트 기능 감사표

최종 갱신: 2026-09-07

## 목적

이 문서는 플랫폼 기능을 추가했지만 AI 연결을 빠뜨리는 일을 막기 위한 기준표다. 실제 런타임 카탈로그는 `backend/aiCapabilityCatalog.js`, 실제 도구와 실행 경계는 `backend/aiAgentRuntime.js`가 단일 기준이다. `/api/ai/capabilities`는 로그인한 사용자가 현재 배포본의 도구 수, 기능 영역, 제한 사유를 확인할 수 있게 한다.

## 현재 연결 범위

현재 13개 제품 영역, 100개 도구가 등록돼 있다. 도구 수는 코드 변경에 따라 늘어날 수 있으므로 배포본의 정확한 값은 `/api/ai/capabilities`를 기준으로 한다.

| 영역 | AI가 조회·실행하는 기능 |
| --- | --- |
| 대화 기억 | 실제 저장 대화 키워드 검색, 추측 답변 방지 |
| 파일 관리자 | 목록·검색·텍스트/코드 읽기·속성·생성·복사·이동·휴지통·날짜 정리 |
| 저장공간/복구 | 계정/경로 사용량, 휴지통, 파일 버전, 전체 드라이브 복구 지점, 활동·최근·즐겨찾기, 각 복원 |
| 친구 | 친구·요청·차단·온라인 상태 조회, 요청/수락/거절/해제/즐겨찾기/차단 |
| 채팅 | 방·메시지 조회, 1:1/그룹 전송, 파일 전송, 그룹 생성·초대·응답·나가기, 방장/부방장/강퇴/파기, 받은 첨부 저장·읽음 |
| 알림 | 목록·미확인 수 조회, 하나/전체 읽음 처리 |
| Note Studio | 노트북·노트·삭제 노트·버전 조회, 노트북/노트 생성·수정·휴지통·복원·버전 복원, NAS 첨부 연결/해제, Office 문서 연결, 제한 Python 실행 |
| 문서 변환 | 변환 가능 형식, 작업 상태, 변환/병합/템플릿 작업 생성, 취소·재시도 |
| 연동 PC | 장치와 연결·동기화 상태 조회, 동기화 일시 정지/재개, 장치 등록 해제 |
| 공유 링크 | 목록·접근 로그, 생성·상세 설정·일시 정지/재개·주소 재발급·비활성화 |
| 회의 | 회의 상태·내 회의·공개 회의 조회, 정규 회의 설정·시작·임시 회의 저장 |
| 내 계정 | 로그인 유지 상태 조회·변경 |
| 관리자/마스터 | 사용자·가입 대기·할당량, CPU/RAM/디스크/온도/자원 기록 조회, 역할·용량·전체 접근 변경, 가입 승인/거절, 자원 보호 정책 |

## 의도적으로 AI에 위임하지 않는 경계

- 비밀번호, API 토큰, SSH 개인키, 공유 비밀번호 등 비밀의 입력·출력·저장
- 계정 생성·삭제, 계정 비밀번호/루트 비밀번호/마스터 키 변경
- 파일·노트·휴지통·공유 기록의 영구 삭제
- 브라우저 파일 선택, 바이너리 업로드/다운로드/미리보기 스트림
- NAS Driver의 heartbeat·청크 동기화·세션 등록·업데이트 공급자 내부 프로토콜
- 카메라·마이크·화면 공유, WebRTC와 실시간 회의 Socket 제어
- 공개 링크 방문자의 게스트 인증·다운로드

이 항목은 구현 누락이 아니라 인증 경계 또는 사용자 장치 동의 경계다. AI는 대신 정확한 화면 위치와 사용자가 직접 해야 하는 한 단계만 안내한다.

## 안전 규칙

1. 모든 조회는 현재 로그인 쿠키로 기존 플랫폼 API를 호출하므로 서버의 계정·역할·경로 검증을 우회하지 않는다.
2. 변경 도구는 최신 사용자 실행 의도와 일치할 때만 계획을 만들 수 있다.
3. 다른 사용자는 승인 전에 UID와 로그인 ID를 고정하고, 실행 직전에 다시 대조한다.
4. 광범위 복원, 장치 해제, 방장 위임·강퇴·방 파기, 사용자/자원 정책, 공유 주소 재발급은 `critical`이며 `auto_all`에서도 개별 승인한다.
5. Python과 문서 변환은 서버 자원 보호 정책을 통과해야 하며 자동 승인하지 않는다.
6. 파일 읽기는 허용된 텍스트/코드 확장자와 크기 상한 안에서만 수행하고 숨김·인증·내부 경로를 차단한다.
7. 짧은 후속 답변은 30분 이내 미완성 작업에만 결합하며 취소 문장은 즉시 작업 권한을 폐기한다.

## 새 기능 완료 기준

앞으로 플랫폼 기능을 추가할 때 다음을 모두 충족해야 완료다.

1. 사용자 UI와 서버 API의 권한·입력·실패 상태를 먼저 정의한다.
2. AI가 다룰 사용자 기능이면 조회 도구와 필요한 변경 도구를 함께 추가한다.
3. `aiCapabilityCatalog.js`의 정확한 제품 영역에 등록한다. 미등록 도구는 테스트 실패다.
4. 변경 도구에는 자연어 의도 규칙, 실행 계획, 위험 등급, 승인 화면 설명, 실행 직전 재검증이 있어야 한다.
5. 일반 질문·과거형·부정문이 변경 권한을 만들지 않는 질문 행렬을 추가한다.
6. 실제 API 호출 경로 테스트, 전체 백엔드 테스트, 프런트 프로덕션 빌드를 통과한다.
7. NAS 배포 뒤 일반 사용자와 관리자 계정으로 실제 화면 대화를 검증하고 릴레이와 프로젝트 로그에 결과를 기록한다.
